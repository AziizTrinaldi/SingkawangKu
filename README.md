# SingkawangKu

Website panduan wisata Kota Singkawang, Kalimantan Barat, untuk pendatang yang baru pertama kali berkunjung. Isinya mengenalkan kota, destinasi wisata, kuliner, cafe, oleh-oleh, dan kegiatan budaya yang rutin ada di Singkawang.

🔗 **Demo:** https://USERNAME.github.io/singkawangku/

## Halaman

| Halaman | Isi |
| --- | --- |
| `index.html` | Beranda, sejarah singkat & asal-usul nama Singkawang, kamus mini bahasa Hakka |
| `destinasi.html` | Sorotan tempat unggulan dan 16 tempat (wisata, kuliner, cafe, oleh-oleh) |
| `kegiatan.html` | Hitung mundur Cap Go Meh dan kalender kegiatan budaya sepanjang tahun |

## Fitur

- Filter kategori dan pencarian tempat
- Pop-up detail tempat (alamat, jam buka, harga) dengan tombol ke Google Maps
- Kamus mini bahasa Hakka dengan kartu yang bisa dibalik
- Hitung mundur menuju Cap Go Meh
- Peta Kota Singkawang di footer

## Bahasa Pemrograman

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- JavaScript
